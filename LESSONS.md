# Combined lessons

These are requirements distilled from evidence, not inherited implementation.
Historical issues remain readable after superseded closure.

| Evidence | Lesson carried forward | New recurrence check |
|---|---|---|
| [Factory004 #130](https://github.com/edoworks/factory/issues/130) | One useful app before platform generalization; no proven claim before a new App Store release | Explicit parity/qualification ledger |
| [Lineage #131](https://github.com/edoworks/factory/issues/131) | One active destination; preserve partial evidence and dirty work | Canonical repo and backup readback |
| Old factory init at dab21a8a | Renaming a template is not product generation | Change meaningful spec data, regenerate, execute changed behavior |
| [Analyzer #121](https://github.com/edoworks/factory/issues/121) | A process exit or test count alone can mask tool failure | Propagate failures; distinguish engine/browser/native gates |
| [Hosted evidence #99](https://github.com/edoworks/factory/issues/99) | Script output is not rendered or physical-device evidence | Execute rendered flows; retain native/device gaps |
| [Storage #100](https://github.com/edoworks/factory/issues/100), [#112](https://github.com/edoworks/factory/issues/112) | Global disk drift does not justify indiscriminate cleanup | Bound own temporary outputs; never delete other work |
| [Controller #133](https://github.com/edoworks/factory/issues/133) | Mutable source must not self-authorize privileged operations; unrun tests are not passes | No privileged bootstrap; blocked checks stay blocked |
| [Superseded contracts #116](https://github.com/edoworks/factory/issues/116) | Closure reason must reflect actual outcome | Mark old backlog not_planned, never fixed |
| Couch PRD read-only oracle; coordinator defect handoff | Saved meanings must not silently follow new globals; invalid input must not poison trusted state | Bind saves to complete spec identity; validate before transition |
| Coordinator optional-AI defect handoff (not independently reproduced here) | Mutable adapter input/output can poison fallback, including after timeout | Before any future AI integration, test private baseline, input clone, output clone and late mutation |
| Factory Charter at dab21a8a | Human release authority, clean-checkout reproducibility, recovery and no telemetry remain useful | Offline generator, source/spec/toolchain manifest, no deployment command |

No old code is reused. LICENSE, TRADEMARKS.md and SECURITY.md are retained
governance text. No prior release, old workflow or proposed protected controller
is presented as a qualification of the new implementation.
